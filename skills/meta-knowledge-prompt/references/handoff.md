# 不同任务怎样交接

同一句“帮我优化”可能是要改一张静态图、改一次操作、改一段口播，或者改变一个判断。先看接收提示词的工具能读取什么、能交付什么。能从用户原话判断，就无须再问工具品牌。

| 下游要做的事 | 提示词里必须带走的细节 | 容易造成的误会 |
|---|---|---|
| 改现成文案 | 原句、读者、要保留的事实与口头表达；按什么顺序改 | 把个人经历润色成原文没有的故事；改稿任务只交写作建议 |
| 设计界面或海报 | 观看情境、首要动作、不能消失的信息；若有现成设计规范就跟随 | 把“有设计感”全翻成加阴影；把报名地点写成活动地点 |
| 剪已有视频 | 随附原片、哪些镜头和声音确有其物、能否补拍、能否剧透；剪辑或时间线建议二选一 | 编造拍摄素材、秒数或对白；让只读文字的 AI 输出剪好的影片 |
| 分析一批反馈 | 数据在何处、计数单位、缺失身份或重复记录的处理、什么字段能回查 | 把评论条数当作独立人数；把关联或提及写成证实的原因 |
| 解释或教学 | 学习者已会什么、在哪一步卡住、新例子要检验哪个能力 | 模仿例题就算会迁移；例题与测验只换数字、考点却没变 |

**可用的三种起句**

- 材料齐全时，把它直接带入：“把下面这四句话改成一段 20 秒左右的现场介绍，保留我说的……”
- 材料将在下个窗口提供时：“我会在下一条粘贴 12 条反馈。请等我发完再归类……” 接收方读完就知道下一步要等什么。
- 用户还没有素材时，先指向能交付的上一步：“先给我一个只用手机能拍的三镜头方案，标明每镜要记录的可见动作。”这与“用现有素材剪出成片”是两种任务。

**冷启动检查**：复制块里的每个“这里”“上面”“继续按这个改”，在新对话里分别指向什么？删掉“资深专家”后，有没有少掉一个可执行决定？最后问“如果执行者猜错，我怎样从交付物上发现？”若检验只能靠满意度，换成一个更便宜的动作，比如逐句回查、只听前三秒、或让一位新读者指出下一步。
